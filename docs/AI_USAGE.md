
# AI Usage Documentation

## 1. Purpose of AI Assistance

AI tools were used as assistants during the development of this PostgreSQL database project.

The goal was to understand SQL concepts, generate example queries, and review the database design.

## 2. How AI Was Used

AI assistance was used for:

- Suggesting the Hotel Booking project idea.
- Designing the database schema and relationships.
- Generating SQL statements for table creation.
- Creating sample data for guests, rooms, and reservations.
- Preparing CRUD operations.
- Writing INNER JOIN and GROUP BY queries.
- Explaining pagination using LIMIT and OFFSET.
- Demonstrating transactions using COMMIT and ROLLBACK.
- Creating an index and interpreting EXPLAIN ANALYZE results.
- Reviewing and explaining SQL concepts and query results.

## 3. Human Contribution

The SQL statements were reviewed and executed manually using pgAdmin 4.

Query results were checked to verify that the database operations worked correctly.

Execution results were also shared with AI to help interpret the output and understand PostgreSQL behavior.

## 4. Learning Outcomes

Through this project, the following concepts were practiced:

- Relational database design.
- Primary and foreign keys.
- Database constraints.
- CRUD operations.
- Table joins and data aggregation.
- Pagination.
- Transaction management.
- Indexing and query execution analysis.

## 5. Conclusion

AI was used as a learning and development assistant, not as a replacement for understanding or testing the SQL code.

The project helped demonstrate how AI assistance can support database development while the developer remains responsible for reviewing, executing, and verifying the results.
